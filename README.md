# Переводчик RU ⇄ TR на Soniox (живой диалог)

Одна страница `index.html`, без сервера: слушает микрофон, Soniox сам определяет язык и переводит
в обе стороны (`translation.type = two_way`). Реплики показываются как в чате: слева мои (крупно —
перевод для собеседника), справа собеседника (крупно — перевод для меня).

## Запуск

1. Открыть https://coodix.github.io/live-translator/ (iPhone, любой браузер) или локально
   `index.html` в Chrome (двойной клик по файлу). Сайт — GitHub Pages из репозитория
   `coodix/live-translator`: обновить = `git push` в `main`.
2. «Старт» → при первом запуске спросит ключ Soniox (console.soniox.com → API Keys).
   На Маке ключ уже лежит в Связке, скопировать его в буфер:
   `security find-generic-password -s soniox-api-key -w | pbcopy` → вставить в окно «Ключ».
3. Разрешить микрофон. Нужен интернет (Wi‑Fi или раздача с телефона).

Ключ хранится только в localStorage этого браузера (кнопка «Ключ» — заменить или удалить).
Важно: на `file://` все локальные HTML-файлы в Chrome делят одно хранилище, так что открывать
рядом чужие скачанные .html не стоит.

При открытии страница сразу начинает новый разговор и слушает (⚙ → «Автостарт»; `?start` —
включить, `?nostart` — выключить для этой ссылки). Если браузер не даёт звук без нажатия, просит один тап.
На телефоне при уходе в фон останавливается и продолжает при возвращении; после 10+ минут
отсутствия начинает новый разговор.

Тот же язык после паузы ≥ 3 с (⚙ → «Новая реплика после паузы») — новая реплика.

История: прошлый разговор уходит в «🕘 История», когда начинаешь новый (кнопка «Новый» или
повторное открытие страницы). Хранится в localStorage этого браузера (до 300 разговоров), оттуда
можно открыть, скачать `.md` или удалить. На iPhone у Safari и у иконки на экране «Домой» хранилища
разные: ключ и история в каждом свои.
`index.html?demo` показывает интерфейс без ключа и микрофона.
На телефоне «Старт/Стоп» — широкая кнопка внизу экрана. Пока идёт подключение, на ней спиннер
и она не нажимается.

Action Button / «Команды»: схема `webapp://…` иконку с экрана «Домой» не открывает (23.11 на
iPhone не сработал ни один вариант; по форумам работала только в бете iOS 26). Рабочий путь —
команда «Открыть URL-адреса» с `https://coodix.github.io/live-translator/?start`: страница
открывается во вкладке Safari, ключ и история там свои. Чтобы иконка на «Домой» делила с ней
хранилище, её надо добавить из Safari с выключенным «Открыть как веб-приложение».

## Как устроено

- Микрофон → PCM 16 кГц (если браузер не даёт 16 кГц, берётся родная частота и передаётся в
  конфиге) → `wss://stt-rt.soniox.com/transcribe-websocket`, модель `stt-rt-v6` (поле «Модель»).
  Ключ передаётся в WebSocket-протоколе `soniox-api-key`, запасной путь — поле `api_key` в
  конфиге. Оба способа проверены 23.11 с постоянным ключом.
- Реплики делятся по языку (мой язык → слева, остальные → справа), токены перевода цепляются к
  последней реплике своего исходного языка. При обрыве связи переподключается сам и досылает
  накопленный звук (до ~30 с).
- Soniox закрывает сессию с `408 Request timeout`, если ~20 с не получает звука (проверено 14.11).
  Поэтому страница шлёт `{"type":"keepalive"}`, когда звук не уходит 5 с, и следит за микрофоном:
  если аудио встало дольше 3 с, будит AudioContext, а через 8 с перезапускает микрофон.
- Слушать может только одна вкладка: запуск в новой вкладке останавливает старую.
- До 23.11 был `server.py` (менял постоянный ключ на временный и писал `transcripts/*.md`); убран.
  Старые расшифровки остались в `transcripts/`.
